Typography

The face and weight the whole app is set in. Sizes are a single multiplier on the shipped scale — its proportions are the design.

Upload a font file

TTF, OTF, WOFF or WOFF2. The app downloads it once and caches it on the device, so it keeps working offline.

Logo & icon

PNG, JPEG, WebP or GIF, up to 2 MB. With none set, the app draws its own mark — that fallback is always available and is what a reset returns to.

Colour theme

Both colourways are stored. The app follows the device setting unless the user has chosen one, so leaving light unstyled would show white text on white for anyone on a light phone.

Music player theme

Each player surface picks its own design, independently of the app theme. Every variant uses the colours above.
